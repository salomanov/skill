### [x] ВЫПОЛНЕНО (2026-11-12): Регламент жизненного цикла `AGENT_RECOMMENDATIONS.md` (Архивация и очистка)
- **Источник**: Проект «Router_Workspace» (диалог `6dff03e2-0913-483a-a1af-a5c0daa95304`).
- **Проблема**: Файлы `AGENT_RECOMMENDATIONS.md` в проектах-реципиентах не очищаются и не помечаются после успешного внедрения рекомендаций. Из-за этого при последующих сессиях агенты повторно анализируют уже закрытые задачи и тратят контекст на неактуальные предложения.
- **Решение**: Внедрить в правила скилла `project-guardian` (Раздел 13) обязательный жизненный цикл рекомендаций:
  1. **Явные статусы**: Каждая рекомендация маркируется `[ ] ТРЕБУЕТ ВНЕДРЕНИЯ: <Название>` или `[x] ВЫПОЛНЕНО (ГГГГ-ММ-ДД): <Название>`.
  2. **Архивация**: После закрытия задачи блок переносится в `docs/APPLIED_RECOMMENDATIONS.md` (или помечается `[x]`).
  3. **Гигиена активного файла**: В `AGENT_RECOMMENDATIONS.md` остаются только открытые задачи. При полном закрытии файл очищается или удаляется.
- **Верификация**: Закреплено в Разделе 13 `SKILL.md`, подтверждено `security-gate.ps1`.

### [ ] ТРЕБУЕТ ВНЕДРЕНИЯ: Использование именованных сырых строк в C++ (`R"raw(...)raw"`) при встраивании HTML/JS в Web UI
- **Источник**: Проект «Ночник» (ESP8266 + SettingsGyver), файл `src/web_ui.cpp`.
- **Проблема**: При встраивании HTML-разметки и JS-скриптов с вызовами функций (`onclick="myFunc()"`) стандартный синтаксис `R"( ... )"` преждевременно закрывается первой же встреченной конструкцией `)"` в JS-коде, вызывая каскадный сбой компиляции `expected ')' before style` и `missing terminating " character`.
- **Решение**: Всегда использовать именованные маркеры сырых строк C++: `R"rawhtml( ... )rawhtml"`. Это полностью исключает конфликт с `)"` внутри встроенного JavaScript или CSS.
- **Верификация**: `pio run` компилируется без синтаксических ошибок.

### [ ] ТРЕБУЕТ ВНЕДРЕНИЯ: Безопасный поиск подстрок JSON в C++ без экранирования кавычек
- **Источник**: Проект «Ночник», файлы `src/main.cpp`, `src/mqtt_manager.h`.
- **Проблема**: Конструкции вида `str.indexOf("\"Key\":")` при генерации или обработке скриптами могут превращаться в `""Key":`, что приводит к ошибке компилятора GCC `unable to find string literal operator 'operator""Key'`.
- **Решение**: Искать просто `str.indexOf("Key")` либо использовать сырую строку `str.indexOf(F("Key"))` без внутренних двойных кавычек.
- **Верификация**: `pio run` успешно распознаёт ключи телеметрии MQTT/HTTP.
