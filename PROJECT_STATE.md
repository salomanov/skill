# Состояние Проекта: Project Guardian (Skill & Automation)

> Данный файл автоматически ведется агентом и служит долговременной памятью проекта.
> При начале новой сессии агент считывает этот файл в первую очередь.

---

## 1. Описание и Назначение
- **Цель проекта**: Универсальный скилл и набор правил для Google Antigravity / Gemini CLI, обеспечивающий:
  1. Автоматическое сохранение памяти проекта (`PROJECT_STATE.md`).
  2. Точки отката (checkpoints) и локальные бэкапы перед модификацией кода (`checkpoint.ps1`, `rollback.ps1`).
  3. Отдельный изолированный бэкап при каждой удачной прошивке устройств с сохранением бинарников (`.bin`, `.hex`, `.elf` и др.) и тегированием в Git.
  4. Автоматический коммит и пуш в Git при наличии настроенного `remote`.
  5. Автономный поиск и загрузку недостающих скиллов из каталога `sickn33/agentic-awesome-skills` (`install-skill.ps1`).
  6. Обязательную интеграцию с `graphify` для архитектурного анализа кодовой базы.
- **Репозиторий**: https://github.com/salomanov/skill.git

## 2. Стек Технологий и Инструменты
- **Рантайм и шелл**: PowerShell 5.1+ / Windows
- **Платформа**: Google Antigravity / Gemini CLI
- **Интеграции**: Git, GitHub REST API, Graphify, Agentic Awesome Skills Catalog

## 3. Архитектура и Структура Репозитория
```text
/
├── SKILL.md                          # Главный файл скилла с frontmatter и регламентом
├── scripts/

│   ├── rollback.ps1                  # Скрипт отката к точке восстановления
│   └── install-skill.ps1             # Скрипт автономной установки скиллов из GitHub

├── .gitignore                        # Исключение .backups/ и временных файлов
├── PROJECT_STATE.md                  # Память проекта
└── README.md                         # Документация и инструкция по установке
```
