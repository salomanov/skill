## [2026-11-20] Именованные сырые строки в C++ (`R"rawhtml(...)rawhtml"`) при встраивании HTML/JS в Web UI
- **Источник**: Проект «Ночник» (ESP8266 + SettingsGyver), файл `src/web_ui.cpp`.
- **Симптом**: Стандартный синтаксис `R"( ... )"` преждевременно закрывается первой встреченной конструкцией `)"` в JS-коде (`onclick="myFunc()"`), вызывая каскадный сбой компиляции GCC.
- **Внедрение**: Закреплено в `SKILL.md` (Раздел 10.13) как обязательное правило для всех C/C++ прошивок с встроенным Web UI.
- **Верификация**: Закреплено в `SKILL.md`, пройдена проверка `security-gate.ps1`.

## [2026-11-20] Безопасный поиск подстрок JSON в C++ без экранирования кавычек
- **Источник**: Проект «Ночник», файлы `src/main.cpp`, `src/mqtt_manager.h`.
- **Симптом**: Конструкции вида `str.indexOf("\"Key\":")` при обработке скриптами превращаются в `""Key":`, вызывая ошибку GCC `unable to find string literal operator 'operator""Key'`.
- **Внедрение**: Закреплено в `SKILL.md` (Раздел 10.13) — использовать `str.indexOf("Key")` или `R"raw("Key":)raw"`.
- **Верификация**: Закреплено в `SKILL.md`, пройдена проверка `security-gate.ps1`.
