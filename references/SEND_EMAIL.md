# Universal Email Dispatcher (Project Guardian Module)

## 19. Универсальная отправка на почту (Universal Email Dispatcher v1.7.11)

Правило обязательно для всех диалогов и сессий Antigravity / Gemini CLI.

### 19.1. Поведенческие триггеры
При фразах пользователя:
- *«напиши мне на почту»*, *«скинь мне на почту»*, *«отправь на email»*, *«вышли отчет на почту»*, *«отправь файл на почту»*:
агент обязан **не переспрашивать адрес и настройки**, а автоматически использовать настроенный шлюз Project Guardian.

### 19.2. Архитектура и безопасность (SEC-002 Invariant)
- **Конфигурация учетных данных**: Хранится строго вне репозиториев проектов в глобальном файле `~/.gemini/config/email_settings.json`:
  - `smtp_server`: `smtp.mail.ru` (порт 465 SSL)
  - `smtp_user`: `sender@example.com`
  - `default_recipient`: `recipient@example.com`
  - `smtp_pass`: пароль приложения Mail.ru
- Пароли и токены почты **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** хардкодить в исходный код, коммиты Git или локальные скрипты проектов.

### 19.3. Команда отправки
Агент выполняет отправку через универсальный скрипт:
```powershell
& "C:\Users\Salomanov\.gemini\config\skills\project-guardian\scripts\send-email.ps1" `
    -Subject "<Тема письма>" `
    -Body "<Текст отчета или пояснение>" `
    [-Attachments "<путь_к_файлу>", "<путь_к_файлу_2>"] `
    [-Html]
```

### 19.4. Регламент ответа пользователю
После отправки агент сообщает в чат:
1. Адрес получателя (`recipient@example.com`).
2. Тему письма.
3. Список прикрепленных файлов (если были вложения).
4. Статус отправки (exit code 0 / [OK]).
